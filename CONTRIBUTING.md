# Contributing

1. Install Go (the version in `go.mod`).
2. `make test` must pass. It runs `go vet` and the tests with the race detector.
3. Use Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`). They drive the version and the release notes.
4. Changes to the wire format must update `docs/protocol.md` and `internal/protocol` together, and bump the protocol version when they are not backward compatible.
5. Do not edit `CHANGELOG.md`. It is generated by release-please.

The agent must stay platform agnostic.
It must not depend on Docker, Kubernetes, a cloud provider, or any specific reverse proxy.
